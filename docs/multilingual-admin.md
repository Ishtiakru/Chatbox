# Experimental multilingual admin interpretation

This is an isolated Android test prototype, **not arbitrary app/code modification** or a production deployment. Authorized Spark admins may request the already-supported welcome text, theme preset and menu position. The normal deterministic parser runs first. If it cannot interpret the request, the explicitly enabled Android test lab can ask Firebase AI Logic to suggest one action. Supported languages depend on the model and are not guaranteed. Ambiguous, unsupported, malformed, oversized or unrecognized suggestions are rejected.

The request may be sent to Google Gemini, including under the applicable free-tier terms. Do not submit secrets, private chat content or sensitive information. Nothing is silently applied: the exact proposed value must be displayed and confirmed. The model's response is untrusted; an allowlist validator converts it to an existing bounded command, then the existing service re-parses it and checks the exact preview. Firestore rules enforce verified admin identity and recent authentication at write time; a client-side role or model is not an authorization boundary. Unsupported requests cannot change code, rules, accounts, integrations, or deployed binaries.

`VITE_ENABLE_EXPERIMENTAL_MULTILINGUAL_ADMIN=true` is an opt-in only with Spark admin, native test mode, Firebase AI provider, and Android AI lab enabled. The isolated test-APK workflow sets it, but existing APKs are unaffected. Model availability, real Android Play Integrity/App Check, Google sign-in, quota, language understanding, and a real two-account write remain unverified. Any future production solution for arbitrary app modifications needs a separately secured development/build/review/release pipeline; changing public source or shipping an APK is not equivalent to changing an allowlisted runtime setting. The owner must approve and review such a pipeline and its costs.
